# claude-config
Dotfiles for Claude Code. `install.sh` symlinks them into place:

| File | Target |
|---|---|
| settings.json | ~/.claude/settings.json |
| CLAUDE.md | ~/.claude/CLAUDE.md |
| hooks/ | ~/.claude/hooks/ |
| agents/ | ~/.claude/agents/ |
| statusline.sh | ~/.claude/statusline.sh |
| bin/* | ~/bin/ |
